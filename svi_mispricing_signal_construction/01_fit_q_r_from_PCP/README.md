# 01_fit_q_r_from_PCP

## Purpose

This project estimates the risk-free rate (`r_reg`) and dividend yield (`delta_reg`) for option quote groups using put-call parity (PCP). The final dataset maps these estimates back to the full quote file so that downstream implied-volatility calculations can use consistent discount-factor inputs.

## Folder Structure

```text

  raw/
  intermediate/
  processed/

  report/

```

