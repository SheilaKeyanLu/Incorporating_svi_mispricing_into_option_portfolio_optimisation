# 03__fit_in_SVI_W_I

## Purpose

This project fits SVI volatility slices using equal weighting (`W=I`). It produces fitted SVI parameters, stability-margin diagnostics, and a calibration-quality report. Plotting code is intentionally excluded from this project so that equal-weighting calibration remains a data and diagnostics step only.

## Folder Structure

```text
03__fit_in_SVI_W_I/
data/
  raw/
  intermediate/
  processed/
scripts/
plot/
output/
  report/
  figures/
README.md
```

## Required Python Packages

- `numpy`
- `pandas`

The scripts also import shared SVI utilities from the repository-level `common/` folder.

## Required Input Files

Place the following file in `data/raw/`:

- `option_quotes_with_iv.csv`

This file is the processed output of the Black-Scholes implied-volatility project.

## Run Order

Run the scripts from the project root in this exact order:

```bash
python scripts/01_fit_svi_equal_weighting.py
python scripts/02_summarize_svi_margin.py
```

## Outputs

Intermediate data are saved in `data/intermediate/`:

- `_svi_fit.csv`
- `_svi_fit_margin.csv`
- `_svi_margin_summary.csv`
- `_svi_margin_by_maturity.csv`
- `_svi_margin_by_underlying.csv`

The processed dataset is saved in `data/processed/`:

- `svi_fit_equal_weighting.csv`

Reports are saved in `output/report/`:

- `calibration_quality_equal_weighting.txt`

No figures are generated by this project. The `plot/` and `output/figures/` folders are kept for consistency with the dissertation project structure.
