# calc_greeks

## Purpose

This folder calculates option Greeks from the implied-volatility dataset produced by the SVI mispricing-signal construction pipeline. The output is used as an input for the Delta-Gamma return/risk approximation and the downstream portfolio-optimisation backtests.

The workflow has two components:

- `calc_greeks.py`: reusable Black-Scholes helper functions for prices and Greeks.
- `calculate_greeks_for_quotes.py`: chunked CSV processing script that adds `delta`, `gamma`, `theta`, `vega`, and `discount_factor` to the full option-quote panel.

## Folder Structure

```text
calc_greeks/
  calc_greeks.py
  calculate_greeks_for_quotes.py
  option_quotes_with_iv.csv
  option_quotes_with_greeks.csv
  README.md
```

## Required Python Packages

- `numpy`
- `pandas`
- `scipy`

## Required Input Files

Place the following file in this folder:

- `option_quotes_with_iv.csv`

This file is the implied-volatility dataset generated by:

```text
svi_mispricing_signal_construction/02_calculate_iv_from_BSM/data/processed/option_quotes_with_iv.csv
```

The input CSV must contain:

```text
F
T
implied_volatility
strike_price
option_type
r_reg
beta_K
```

`option_type` should use `C` for calls and `P` for puts. The script uses `-beta_K` as the discount factor and calculates Greeks only for rows with positive `F`, `T`, implied volatility, strike price, and discount factor.

## Run Order

From the `calc_greeks` folder, run:

```bash
python calculate_greeks_for_quotes.py
```

The script reads:

```text
option_quotes_with_iv.csv
```

and writes:

```text
option_quotes_with_greeks.csv
```

The file is processed in chunks of 500,000 rows to reduce memory usage. Progress is printed after each chunk.

## Outputs

The processed output file is:

- `option_quotes_with_greeks.csv`

The output keeps the original columns and appends:

```text
discount_factor
delta
gamma
theta
vega
```
